keyhound
What it catches CI GitHub

Find leaked keys before you push them.

keyhound scans your code, and your git history if you ask, for API keys, tokens and private keys. It prints where each one is, with the secret masked.

$ pipx install git+https://github.com/myanptl/keyhound
  • Python 3.9+
  • Zero dependencies
  • MIT licence

What it catches

25 patterns, plus a Shannon-entropy check for random-looking strings that match none of them. Turn that off with --no-entropy.

  • AWS Access Key ID high
  • AWS Secret Access Key high
  • GitHub PAT (classic) high
  • GitHub OAuth Token high
  • GitHub Actions Token high
  • GitHub Refresh Token high
  • Google API Key high
  • Stripe Secret Key high
  • Stripe Publishable Key medium
  • SendGrid API Key high
  • Slack Bot Token high
  • Slack User Token high
  • Slack Webhook URL high
  • RSA Private Key high
  • EC Private Key high
  • OpenSSH Private Key high
  • PGP Private Key Block high
  • OpenAI API Key high
  • Anthropic API Key high
  • Twilio Account SID medium
  • JWT Token medium
  • npm Token high
  • PyPI API Token high
  • Generic Password medium
  • Generic API Key medium

Options

Run keyhound --help for the full list.

keyhound ./srcScan a folder or a single file. Defaults to the current folder.
--gitAlso scan git history, the last 100 commits by default.
--max-commits NHow far back --git goes.
--severity highOnly report findings at or above this level.
--output jsonMachine-readable output.
-qFindings only, no banner or summary.
--no-colorPlain output. NO_COLOR works too.

In CI

The exit code fails the build when a key turns up.

# .github/workflows/secrets.yml
- uses: actions/checkout@v4
  with: { fetch-depth: 0 }
- run: pipx install git+https://github.com/myanptl/keyhound
- run: keyhound --git --severity high
  • 0clean
  • 1findings
  • 2error
